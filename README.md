# 🚀 Python Local SEO Auditor

A lightweight Python automation tool designed to audit website metadata, response codes, canonical tags, and structured data (`LocalBusiness` schema). Built for technical SEO auditing and local search optimization.

## 📌 Features
- **Technical Inspection:** Checks HTTP Status Codes and response latency.
- **On-Page SEO Verification:** Measures Title Tag & Meta Description lengths with pass/fail flags.
- **Header Structure:** Detects missing or duplicate `<h1>` tags.
- **Local SEO & Schema Audit:** Verifies canonical URL implementation and detects JSON-LD structured data.
- **Automated Reporting:** Exports clean structured audit reports to `.csv`.
